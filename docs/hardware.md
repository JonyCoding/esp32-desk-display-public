# 硬件：接线、供电与外壳

以下数字是 GPIO 编号。换用其他 ESP32 开发板时，按板上的 GPIO 丝印接线。

## 1. 面板（HUB75E 64×64）

| 信号 | GPIO | 信号 | GPIO |
|---|---|---|---|
| R1 / G1 / B1 | 32 / 23 / 25 | R2 / G2 / B2 | 26 / 22 / 27 |
| A / B / C / D / E | 14 / 19 / 13 / 18 / 21 | CLK / LAT / OE | 16 / 17 / 4 |
| GND | 与屏幕电源、ESP32 共地 | 标 `N` 的针 | 留空 |

- **先认 IN 口和 1 脚再插线。** 排线插头与板端从相反方向看会镜像，按丝印信号名接线，不按照片左右或缺口方向推。
- 1/32 扫描必须接 E（GPIO21），库也要求配置有效 E；不接会缺半屏或花屏。
- OE 低有效，固件用它做亮度控制，不要接到固定电平。
- 面板物理上旋转 90° 安装，固件 `setRotation(1)` 已做坐标补偿；换屏或换支架方向时要重新确认这一项。

## 2. 供电

- 外置 **稳压 5V** 分成两路。第一路接 ESP32 的 USB-C，第二路接面板 4 针电源口的 VCC / GND。按丝印和原配线核对极性，两路共地。
- 电源、插头与线材按面板额定电流加上主控负载选择。面板从电源的分支直接取电，供电电流不经过 ESP32。
- USB 刷机前拔掉外置电源，断开 ESP32 的供电支路和 HUB75 信号线，再用数据线直连 Mac。

## 3. 电平

ESP32 是 3.3V 逻辑，HUB75 面板按 5V 信号设计。长时间稳定显示建议用 **74AHCT245 / 74HCT245** 转接板（3.3V 输入兼容）；普通 74HC245 不保证 3.3V 输入被识别为高电平。直接连通常也能亮，但属于超出规格使用。

## 4. MPU6050 / MPU6500（GY-521）

| GY-521 | 接到 | 说明 |
|---|---|---|
| VCC | ESP32 3V3 | 模块板载 LDO，3.3V 供电即可 |
| GND | GND | 与主控共地 |
| SDA | **GPIO 5** | 固件 `MPU_SDA_PIN` |
| SCL | **GPIO 15** | 固件 `MPU_SCL_PIN` |
| AD0 | GND，或有板载下拉时留空 | 地址 **0x68**；接 3V3 会变成 0x69，固件依次探测 0x68 和 0x69 |
| INT | 不接 | 固件 50Hz 轮询 |

- 固件识别 MPU6050（`WHO_AM_I=0x68`）和 MPU6500（`WHO_AM_I=0x70`）。两者使用相同接线。若模块已把 AD0 下拉，AD0 可留空。板上印着 MPU6050 的模块也可能返回 `0x70`，以读到的芯片 ID 为准。
- 若模块已经安装 I²C 上拉电阻，可直接使用板载上拉。
- GPIO5/15 是启动绑定脚，但作为 I²C 已被本项目实测占用且工作正常；不要再分配给别人。
- 装好后第一次上电要 **静置标定**（开机自动采 50×20ms 样本）；挪动过安装角度后调 `/cal` 重标定。
- 方向不对不用重烧：`/lean` 回读 `{sign, swap, lean:[x,y], tilt, taps, armed}`，`/lean?set=-1` 镜像左右，`/lean?swap=1` 交换两轴。


## 5. 外壳

`hardware/enclosure/` 中有三件外壳零件和一个可选的后装支脚。

| 文件 | 用途 |
|---|---|
| [front_frame.stl](../hardware/enclosure/front_frame.stl) | 一体前框，含 7° 后仰桌脚 |
| [back_cover_v3.stl](../hardware/enclosure/back_cover_v3.stl) | V3 主后盖，沿用 170.3 × 170.3 mm 外形和原四角孔位 |
| [service_hatch_v3.stl](../hardware/enclosure/service_hatch_v3.stl) | V3 背开维护小盖 |
| [rear_support_v3.stl](../hardware/enclosure/rear_support_v3.stl) | 贴在 V3 仓底的后支脚，与现有 7° 前脚共用桌面 |

前框用四颗屏幕原配的磁柱螺丝锁进面板螺纹孔。开口 160.5 × 160.5 mm，前沿比灯面高约 1 mm。锁主后盖前确认四颗磁柱头贴紧，屏幕前后和左右都没有松动。打印前框时正面朝下。用 `python3 hardware/enclosure/model.py` 可重新生成前框 STL 和 `enclosure.scad`。

下文的左右方向默认从成品背面看。插好插头后再用实际线弯和净空核对。

V3 维护仓左右外宽 119.3 mm、高 73.15 mm，向后凸 46 mm。仓底距主后盖下沿 20 mm，底板厚 4 mm，两侧内角各加一条 5 mm 斜筋。仓体朝屏幕的一面只留四周连接边，内部开口约 113.3 × 66.15 mm，线束可直接通到屏幕后方。五排横向散热窗位于维护仓和 MPU 安装区之间，每排留 7 mm 中筋。主后盖沿用四角 M3 螺丝。小盖用两颗 M3×8 塑料用螺丝固定，穿孔直径 3.6 mm，塑料柱底孔直径 2.8 mm。从背面看，小盖左下留一个直径 5 mm 的电源线孔，按线身直径预留，孔边距盖底 5.5 mm。

ESP32 固定在仓底的 9 mm 安装柱上，元件面朝下。从屏幕背面看，板中心在后盖中线右侧约 19.3 mm，USB‑C 端朝左。按尺寸占位计算，PCB 右边缘与仓内壁约留 9.3 mm。四根安装柱的孔心距为左右 47 mm、前后 24 mm，M3 底孔直径 2.75 mm。整件打印前可先用实物板核对四孔中心距和 M3 通孔。拆小盖后可从左侧插拔 USB‑C。

主后盖朝屏幕的一面为平整贴床面。背面上方有一对对称的倒角凸台，从屏幕背面看，右侧凸台内设 MPU 凹槽，孔距约 15 mm。两根安装柱端面与贴床面齐平。柱内为直径 2.85 mm、深 5 mm 的 M3 自攻底孔，入口略扩，使用 M3×6 塑料自攻螺丝。试装时核对板孔、杜邦线和 USB‑C 插头的空间，再锁主后盖。可用 `python3 hardware/enclosure/model_back_cover_v3.py` 重新导出两件 STL，需安装 `manifold3d`。

V3 最终版按 STL 的默认朝向平放。ESP32 柱根加斜撑，横向底孔采用尖顶过渡，名义孔宽保持 2.75 mm。小盖内侧台阶与 MPU 凹槽顶面增加斜面过渡。已用 Bambu Studio 的 A1 0.4 mm 喷嘴、PETG、纹理 PEI 板配置离线试切片，两件均为 0.20 mm 层高、4 道墙、20% 填充。主后盖开自动树状支撑，允许从模型上生长，外加 5 mm 裙边。小盖外侧朝下，不开支撑。

后支脚宽 96 mm、前后长 28 mm，宽平的粘贴面朝热床，无需支撑。把它横向居中放在 V3 仓底，后边缘离小盖所在的外平面 1 mm，**较薄的一端朝背面**。高度按约 0.2 mm 的薄胶层补偿。先干摆确认没有顶起前脚，再薄涂胶固定。用 `python3 hardware/enclosure/model_rear_support_v3.py` 重新生成 STL。

## 6. 上电顺序与排查

1. 先接好 GND 与 5V，确认极性，再插信号排线。
2. 上电后面板先黑屏属正常，固件点亮后才出画面；屏幕全白常亮通常是 OE 或 LAT 接错。
3. 偏色、亮度断层：确认 `cfg.setPixelColorDepthBits(6)` 与库的编译期 `PIXEL_COLOR_DEPTH_BITS` 一致（构建脚本已处理，原因见 `tools/firmware.sh` 注释）。
4. 花屏/撕裂：缩短排线、确认 E 线、确认共地。
5. I²C 找不到 MPU：`/api/status` 的 `mpu` 为 `false`，先用万用表确认 SDA/SCL 没有接反、AD0 接地。
